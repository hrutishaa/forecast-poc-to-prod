Forecast: PoC → Production

Five candidate models (seasonal-naive baseline, gradient boosting, and three exponential-smoothing / Holt-Winters models) get the same rolling backtest, and the lowest-error one is picked automatically for each series. Versioned config and a FastAPI service sit behind it. This page shows the precomputed results from that pipeline.
